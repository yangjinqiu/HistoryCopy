# 设计规范

## 1. 视觉风格

### 1.1 整体基调
- **简洁**：信息层级清晰，避免装饰性元素
- **直观**：操作可预测，不隐藏关键功能
- **玻璃质感**：macOS vibrancy 毛玻璃效果

### 1.2 材质
- 面板背景：`.glassEffect()`（macOS 26+ 液态玻璃）
- 卡片背景：`Color.primary.opacity(0.03)`，悬停时 `0.06`
- 卡片边框：`Color.primary.opacity(0.08)`，0.5px
- 圆角：面板 16px，卡片 10px，搜索栏 8px

### 1.3 颜色
- 跟随系统浅色/深色模式自动切换
- 主色调使用系统 accentColor
- 文字使用 primary / secondary 层级
- 删除按钮使用红色

### 1.4 字体
- 系统字体 San Francisco
- 内容：13pt
- 辅助文字（时间、来源）：11pt
- 标题：16pt bold

### 1.5 阴影
- 面板：`shadow(color: .black.opacity(0.15), radius: 20, y: 8)`
- 卡片：无阴影，仅边框

## 2. 布局规范

### 2.1 面板
- 宽度：360px（固定）
- 高度：自适应，最大约 560px
- 弹出位置：屏幕正中央偏上 30px
- 内边距：12px（左右），6px（卡片间距）

### 2.2 结构（从上到下）
```
┌─ 搜索栏 + 设置按钮 ─┐
├─ 分割线 ─────────────┤
├─ 置顶卡片区 ────────┤
├─ 历史卡片列表 ──────┤
├─ 分割线 ─────────────┤
├─ 状态栏（条数/保留）─┘
```

### 2.3 卡片
- 内容区在左，操作按钮在右（悬停显示）
- 文字最多 3 行截断
- 图片缩略图最大高度 120px
- 显示相对时间 + 来源应用名

## 3. 交互规范

### 3.1 打开方式
- 全局快捷键（默认 ⌘⌥V）：屏幕中央弹出
- 菜单栏图标左键点击：弹出面板
- 打开动画：淡入 0.18s easeOut

### 3.2 关闭方式
- 再次按快捷键
- 点击面板外任意位置
- 关闭动画：淡出 0.12s easeIn

### 3.3 卡片操作
- 点击内容 → 复制到系统剪贴板，显示"已复制"提示 0.6s
- 悬停卡片 → 显示操作按钮（淡入淡出 0.15s）
- 置顶按钮 → 切换置顶状态
- 删除按钮 → 直接删除

### 3.4 搜索
- 输入即搜索，实时过滤
- 匹配文字内容（不区分大小写）
- 无结果时显示空状态提示

### 3.5 设置
- 右键菜单栏图标 → 设置
- 或面板右上角齿轮图标
- 独立窗口，玻璃质感

## 4. 菜单栏图标

- 自绘剪贴板轮廓图标
- 尺寸 20x20pt
- 使用 `isTemplate = true` 适配系统明暗模式
- 颜色使用 `secondaryLabelColor`
